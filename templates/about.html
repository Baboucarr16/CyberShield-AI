About

What CyberShield AI is

A Flask-based phishing-screening demo that turns URL forensics into advice a non-expert can act on. Built for learning, project review, and portfolio demonstration.

Detection approach

  1. Parse — protocol, length, dots, hyphens, @, IP literals, and brand/urgency keywords, expanded to 48 model features.
  2. Score — a Random Forest estimates phishing probability while weighted rules score URL structure; the stronger signal becomes the 0–10 risk score, and 4 or above means phishing.
  3. Explain — every contributing indicator is listed alongside a plain-language recommendation.

Technology

  • Backend — Python, Flask, Jinja templates
  • Analysis — feature extractor + rule engine + 48-feature Random Forest (feature_extractor.py, detector.py, ai_model.py)
  • Frontend — semantic HTML, single CSS file, small progressive-enhancement script
  • Data — no scan contents leave the server; dashboard history stays in your browser

Security disclaimer

CyberShield is an educational screening aid, not a guarantee. A “safe” result does not prove a site is trustworthy, and skilled attacks can evade heuristics. Never enter credentials from an unsolicited link — navigate to sensitive sites via bookmarks or typed addresses, enable multi-factor authentication, and cross-check high-stakes URLs with an up-to-date browser or reputation service.
